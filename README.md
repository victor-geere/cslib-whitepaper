# CSLib White Paper

A readable HTML edition of **CSLib: The Lean Computer Science Library**
(Barrett, Chaudhuri, Montesi, Grundy, Kohli, de Moura, Rademaker, and
Yingchareonthawornchai; arXiv:2602.04846, 4 February 2026).

**Live site (after Pages is on):** [https://victor-geere.github.io/cslib-whitepaper/](https://victor-geere.github.io/cslib-whitepaper/)

Open the HTML directly from this repo: [index.html](./index.html).

This is a typeset web edition of the original PDF. Wording, section
structure, figures, Lean/Boole listings, footnotes, and bibliography
numbering follow the paper. Layout is rebuilt for the screen: serif
body type, a persistent table of contents, syntax-highlighted code,
and linked citations.

## Enable the public site

GitHub Pages has to be switched on once in the repo settings:

1. Open [Settings → Pages](https://github.com/victor-geere/cslib-whitepaper/settings/pages)
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save. The site will be at https://victor-geere.github.io/cslib-whitepaper/
