# CSLib White Paper

A readable HTML edition of **CSLib: The Lean Computer Science Library**
(Barrett, Chaudhuri, Montesi, Grundy, Kohli, de Moura, Rademaker, and
Yingchareonthawornchai; arXiv:2602.04846, 4 February 2026).

**Read it here:** [https://victor-geere.github.io/cslib-whitepaper/](https://victor-geere.github.io/cslib-whitepaper/)

This is a typeset web edition of the original PDF. Wording, section
structure, figures, Lean/Boole listings, footnotes, and bibliography
numbering follow the paper. Layout is rebuilt for the screen: serif
body type, a persistent table of contents, syntax-highlighted code,
and linked citations.
